# AI 通用助手竞品分析

四款 AI 通用助手（ChatGPT、Claude、豆包、Kimi）的竞品分析，以静态网页形式呈现。

## 分析结构

1. **入选逻辑** — 产品筛选标准与公式推导
2. **产品概况** — 发展历程、订阅方案、核心用户群
3. **能力对比 · 模型层** — 旗舰模型信息、Benchmark 数据、LM Arena 排名
4. **能力对比 · 应用层** — 记忆系统、用户私有信息、实时信息、沙箱、外部系统、定时任务、多模态生成
5. **思考** — 总结与展望

## 技术栈

纯 HTML + CSS + JS，零依赖，零构建步骤。直接打开 `website/index.html` 即可浏览。

## 目录结构

```
website/
├── index.html              # 封面 + 分析框架树状图
├── pages/                  # 各章节页面（共 15 页）
├── css/                    # 样式（设计令牌 / 排版 / 组件 / 布局 / 动画）
├── js/                     # 导航 + 滚动动画
└── assets/                 # 字体资源
```

## 视觉风格

- **正文**：机构研究风 — 白底、宋体标题、学术表格、大量留白
- **插图**：手绘风 — SVG feTurbulence 滤镜 + 不规则圆角 + 微旋转
